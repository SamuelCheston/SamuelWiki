## Project Ecosystem

- **HRPAuth**: Core authentication service (OAuth2, Yggdrasil-API).
- **HASkinLib**: Public skin library square.
- **WinnerProxy**: Reserved UUID support for Mojang players.
- **HASkinProxy**: API translation proxy for skin loaders.
